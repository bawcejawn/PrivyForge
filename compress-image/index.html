    Which format should I choose?

    JPEG

    Best for photos when you need maximum compatibility (email, old software). Quality 70–80 is visually identical to the original for most photos.

    WebP

    The best all-round choice for websites. Supported by every modern browser, usually 25–35% smaller than JPEG, and supports transparency.

    AVIF

    The newest format, often 20–50% smaller than WebP. Encoding is slower, so give large batches a moment. Supported by current Chrome, Edge, Firefox and Safari.

    PNG

    For logos, screenshots and graphics with sharp edges or transparency. PrivyForge reduces PNGs to an optimized 256-color palette (like TinyPNG) at quality below 95, and compresses losslessly at 95 and above.

    Frequently asked questions

    Are my images uploaded to a server?

    No. Compression runs inside your browser using WebAssembly. Your images never leave your device, and the tool keeps working with your internet turned off.

    Is there a limit on file size or number of images?

    No daily limits, no file count caps and no watermarks. The only practical limit is your device's memory; extremely large images (over ~100 megapixels) can be slow on phones.

    Will compressing reduce quality?

    Lossy formats discard detail you're unlikely to notice. Use the before/after slider (click a thumbnail) to check. If you see artifacts, raise the quality.

    Why did a file get "already optimized"?

    If re-encoding would make the file bigger, PrivyForge gives you the original back instead. You'll never download a larger file.

    Can I resize images too?

    Yes. Set a max width and/or height and images are scaled down proportionally. Smaller images are never enlarged.

    Does it work on iPhone and Android?

    Yes, in any modern mobile browser. It also opens iPhone HEIC photos, in any browser, and converts them to JPEG or WebP.
