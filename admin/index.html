Connect to GitHub

The token is kept only for this browser tab and is forgotten when you close it.

How to create the token (2 minutes)
  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → your PrivyForge repo.
  3. Permissions → Repository: Contents: Read and write. Optional: Actions: Read (shows deploy status).
  4. Set an expiry (90 days is sensible). Paste it above. Never commit or share it.

    Pro customers

    PrivyForge has no server, so customer records, payments, refunds and license keys live with your payment provider. That keeps card data and personal details off your site entirely, which is also why the admin never stores them.

    Setup checklist

    1. Create a Lemon Squeezy store (it's the merchant of record, so it handles sales tax/VAT for you).
    2. Add a product "PrivyForge Pro" (e.g. $3/month or $25/year) and turn on License keys.
    3. Paste the checkout link into Settings → Pro checkout URL and the Support "Go ad-free (Pro)" button.
    4. Manage customers, refunds and keys in the Lemon Squeezy dashboard (links below).
