Merge PDF files — without uploading them

Combine any number of PDFs into one document, in the order you choose. Everything happens in your browser, so private documents stay private.

Drop PDFs here or click to choose Add as many as you like · drag rows to reorder (or Alt + ↑/↓)

    How to merge PDFs

    1. Add your PDFs by dragging them in, clicking the box, or pasting them. Add more at any time; each row shows the page count.
    2. Put them in order. Drag rows up or down, or focus a row and press Alt + ↑/↓. The top file becomes the first pages.
    3. Remove any extras with the ✕ on their row.
    4. Click "Merge & download" to save one combined file called merged.pdf.

    Worked example: a job application

    A portal asks for one PDF, and you have three: cover-letter.pdf (1 page), resume.pdf (2 pages) and references.pdf (1 page).

    1. Drop all three in and drag them into that order.
    2. Click merge. The status line reads "Merged 3 files (4 pages, …)" with the final size.
    3. The result has the cover letter on page 1, the résumé on pages 2–3 and the references on page 4. Rename merged.pdf to something the recruiter will recognize.

    Only need part of a file? Pull those pages out first with Split PDF, then merge the result. If the combined file is too big for the portal, run it through Compress PDF.

    What merging keeps

    Pages are copied as they are: text stays selectable, images keep their quality, and each page keeps its own size, so a mix of Letter and A4 pages stays mixed. Nothing is re-compressed, so the merged file is usually about the size of the originals combined. Bookmarks and fillable form fields from the source files may not carry over.

    Tips for a tidy merged file

    • Fix sideways scans before merging. Pages are copied as they are, including their orientation.
    • Compare the page count in the status line with the total you expected. It's a quick way to catch a missing file.
    • Merging never shrinks anything. If the result is too large to send, compress it afterwards.

    Private by design

    Many PDF websites process documents on their own servers. For contracts, bank statements, tax returns and medical records, that's a real risk. PrivyForge uses pdf-lib to merge files locally in your browser. Nothing is sent anywhere, and there are no limits on file count, size or daily use.

    Frequently asked questions

    Is it safe to merge confidential PDFs here?

    Yes. Files are combined inside your browser and never uploaded. You can turn off Wi-Fi after the page loads and it still works.

    How many PDFs can I merge?

    As many as your device's memory can handle. There are no caps or daily limits.

    Can I merge just some pages from each file?

    Extract the pages you want with Split PDF first, then merge those smaller files in the order you need.

    Will links, bookmarks and form fields survive?

    Page content, text and images are kept exactly. Document-level bookmarks (outlines) and interactive form fields from the source files may not carry over into the merged file.

    Will there be a watermark?

    No. The merged file contains only your pages.

    Can I merge password-protected PDFs?

    Not yet. Remove the password in your PDF reader first, then merge.
