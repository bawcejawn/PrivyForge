    How to resize an image

    1. Enter the size you want. Type a width, a height, or both. The quick buttons fill in common widths.
    2. Add your images. Drag them onto the box, click to browse, or paste. Add as many as you like; they all get the same size.
    3. Adjust if needed. Change any number and every image is resized again straight away, so you can try a few sizes.
    4. Download each image, or all of them as a ZIP. File names include the new size, e.g. photo-800x533.jpg.

    Worked examples

    Our test photo is 2400×1600 pixels (368 KB as a JPG).

    • Width 800, keep aspect ratio: the height is worked out for you: 1600 × 800 ÷ 2400 = 533.3, rounded to 800×533. At quality 85 the JPG was 58 KB.
    • Fit inside 1080×1080, keep aspect ratio: the width is the limiting side (1080 ÷ 2400 = 0.45), so the result is 1080×720. Nothing is cropped or stretched.
    • 1080×1080 with aspect ratio off: the photo is squeezed to exactly 1080×1080. Faces and circles will look stretched, so only do this when an exact size matters more than proportions.

    Picking the right size

    Resize to roughly the largest size the image will actually be shown at. Screens with high pixel density (most phones and many laptops) show an image more sharply when it has about twice as many pixels as the space it fills: a photo displayed 600 pixels wide looks crisp at 1200 pixels. Going much bigger only adds file size.

    If a website or form gives you exact dimensions, enter both numbers. If the photo’s shape doesn’t match, keep the aspect ratio on to avoid distortion, and crop it first in your phone’s photo editor if the form insists on a particular shape.

    Resizing a batch

    Every image you add gets the same settings, which is handy for product photos or a set of holiday pictures for a website. With “Keep aspect ratio” on, landscape and portrait photos are each fitted inside your box without distortion: enter 1200 for both width and height, and a 2400×1600 landscape photo becomes 1200×800, while a 1600×2400 portrait becomes 800×1200. Output format “Keep original” saves each image in the format it came in; choose JPG or WebP to convert at the same time.

    Making images smaller vs. resizing

    Resizing changes the pixel dimensions; the file size usually drops a lot as a result, because there are fewer pixels to store. If what you really need is a file under a certain number of kilobytes, use compress to 100 KB, 50 KB or 20 KB: those tools adjust quality first and only shrink the dimensions when they have to. To shrink files without changing dimensions at all, use the image compressor.

    About enlarging

    By default, images are never made bigger than the original, because enlarging can’t add detail that was never captured; it only spreads the existing pixels out and looks soft. Tick “Allow enlarging” when you genuinely need a minimum size, for example a form that rejects images narrower than 600 pixels.

    Private by design

    Resizing happens in your browser using your device’s own graphics engine and WebAssembly encoders. No image is uploaded, so it’s safe for ID documents, client work and family photos. Resized images are saved without the original metadata, including GPS location.

    Frequently asked questions

    Does resizing reduce image quality?

    Making an image smaller removes pixels but looks sharp at the new size. The file is then saved at the quality you choose (85 by default). Enlarging can look soft, which is why it is off by default.

    Can I resize many images at once?

    Yes. Add as many as you like; they all get the same settings, and you can download them together as a ZIP.

    How do I keep the proportions?

    Leave “Keep aspect ratio” ticked. Each image then fits inside the width and height you enter without being stretched.

    How do I make an image smaller in KB?

    Use one of the target-size tools, such as compress to 100 KB, which finds the best quality that fits.

    Are my images uploaded?

    No. Everything happens on your device, and the page works offline after the first visit.
