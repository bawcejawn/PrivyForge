Job portals, government sites and email all impose size limits, and the documents involved — tax returns, IDs, medical records — are exactly the ones you shouldn't hand to a random website. Here are three private options.

## Why uploading is a risk

Server-based PDF tools must receive a full copy of your file. Even when a service promises deletion after an hour, the file has crossed the internet, landed on infrastructure you don't control, and may appear in logs or backups. For a recipe, that's fine. For a passport scan, it isn't.

## Method 1: A browser tool that runs locally (fastest)

Some tools, including [PrivyForge Compress PDF](/compress-pdf/), download their processing code to your browser and never send the file anywhere. To verify any tool's claim, load the page, disconnect from the internet, and try it: if it still works, your file isn't being uploaded.

1. Open [Compress PDF](/compress-pdf/).
2. Drop in your PDF and choose **Recommended** (or **Smallest** for strict limits).
3. Download. Works on Windows, Mac, Linux, iPhone and Android.

## Method 2: macOS Preview

Open the PDF in Preview, choose **File → Export**, set **Quartz Filter** to **Reduce File Size** and save. It's quick, but the built-in filter can be aggressive and make scans hard to read.

## Method 3: Desktop software

Full PDF editors and free utilities like Ghostscript can compress offline with fine-grained control. They're powerful, but require installing software and (for Ghostscript) using the command line.

## Which should you use?

For a one-off, a local browser tool is fastest and works on any device. On a Mac, Preview is a fine built-in option. If you compress PDFs daily at work, a desktop editor is worth it.
