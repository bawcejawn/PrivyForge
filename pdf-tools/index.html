Free PDF tools that never upload your files

Merge, split and compress PDFs directly in your browser. Your documents stay on your device — which matters when they're contracts, bank statements, tax returns or ID scans.

Why use a PDF tool that doesn't upload?

Most free PDF websites work by sending your file to their servers, processing it there, and sending the result back. Even when a site promises to delete files after an hour, the document has still left your control. These free PDF tools run the same kind of processing inside your browser using open-source libraries (pdf-lib and pdf.js), so the file is only ever read into your device's memory.

You can check this yourself: open a tool, wait for it to load, switch off Wi-Fi, and use it. It keeps working.

Which tool do you need?

  • Combining several documents — for example a signed contract plus its appendices — use Merge PDF. Drag files to set the order.
  • Sending only part of a document, like one page of a lease or a single bank statement, use Split PDF. Type page ranges such as 1-3, 7.
  • Hitting an upload limit on a job portal, government site or email, use Compress PDF. "Recommended" shrinks scans the most; "Lossless" keeps text selectable.

How the PDF tools work

  1. Open the tool and drop your PDF on the box, click to choose it, or paste it.
  2. Set it up: drag files into order, type page ranges, or pick a compression level.
  3. Download. One result saves as a PDF; several results come as a single ZIP.

Example: sending part of a long statement

A landlord asks for proof of income, and you have a 12-page bank statement. Open Split PDF, choose "Extract pages into one PDF" and type 1-2 to keep only the summary pages. If the result is still too large for their upload form, run it through Compress PDF. The rest of the statement never leaves your device — and neither do the two pages you send, until you choose to send them.

Limits worth knowing

There are no daily caps or file-count limits; the only limit is your device's memory. Password-protected PDFs need the password removed first. When merging, page content is copied exactly, but bookmarks and interactive form fields from the source files may not carry over. Compress PDF's Recommended and Smallest levels turn pages into images, so text is no longer selectable; use Lossless when that matters.

Frequently asked questions

Do the PDF tools add a watermark?

No. Your output contains only your pages.

Do they work on a phone?

Yes, in any current mobile browser. Very large documents are faster on a computer.

Can I edit text or sign a PDF here?

Not yet. These tools rearrange and shrink existing pages; they don't change what's written on them.
